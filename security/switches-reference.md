## verbose_permissions

## cli_version_freshness

**Default:** on
**Introduced in:** 0.7.0
**Policy:** [security-baseline.md](./security-baseline.md)

The explicit report path checks tracked CLIs (vercel, supabase, gh, node, pnpm, git, bun, wrangler) against their latest published versions. It reports safe gaps, major gaps, and absent tools for manual action. The report mode (`--report`) is read only and never invokes an installer. `--apply` is the explicit path that runs tracked installers for installed tools.

Settings.json effect: sets `/arkira/cliVersionFreshness` to `true`.

## time_checkpoint

**Default:** off

When on, a Stop hook writes a checkpoint of git facts to auto-memory once the configured interval has elapsed since the last checkpoint, so a long session with no merges can still be resumed after a session clear. ## engineering_principles

**Default:** on
**Introduced in:** 0.35.0
**Policy:** [root-agents.md](../governance/root-agents.md)

When on, Claude and Codex hold every change to four principles per governance/root-agents.md: Think Before Coding (understand the system and form a plan before editing), Simplicity First (prefer the simplest design that works; no speculative abstraction), Surgical Changes (touch only what the task requires; no opportunistic refactor), and Goal-Driven (every change traces to the stated objective and is verified against it). ## mode_routing

**Default:** off
**Introduced in:** 0.38.0
**Policy:** [mode-routing-standard.md](../governance/mode-routing-standard.md)

When on, a UserPromptSubmit hook (hooks/mode-suggest.sh) classifies the submitted prompt with high-precision, heuristic-only patterns and, on an unambiguous match, adds one advisory line nudging a non-default execution mode: a Workflow / ultracode for broad fan-out (whole-repo audits, sweeps, migrations) or /goal for a single end-to-end objective (plan -> review -> build -> verify). It never nudges the default (plain/inline), never calls a model, and stays silent on the vast majority of prompts; a loose keyword like 'workflow' alone does not fire. Off by default because prompt-time nudges become ignored wallpaper unless quiet. Governs execution mode, paired with but distinct from the model-tier policy in governance/model-selection-standard.md. See governance/mode-routing-standard.md.

Advisory only; no settings.json effect.
