# MOBILE

Mobile standards for Arkira apps. Two canonical docs:

- `mobile-compliance-standard.md`: responsive web. Every Arkira web app must be
  fully usable on phones and tablets.
- `native-app-standard.md`: native iOS / Android apps. One sanctioned approach
  (Expo + React Native), shared tokens with web, and store/release gates.

Token primitives for both live in `theme/theme-standard.md`.
