# PROMPTS

Reusable prompts for audits, remediation, reviews, implementation, and governance workflows.

- [`scaffold-repo.md`](./scaffold-repo.md), bootstrap a fresh application repo to the
  Arkira baseline from an empty folder, then hand off to `/arkira-init`. Paste-in,
  stack-agnostic.
- [`audit-prompt.md`](./audit-prompt.md), standardized read-only audit workflow for
  Arkira-governed repos.
